# SyncSpace

A production-ready real-time collaborative document editing platform inspired by Google Docs.

## Features

- Authentication
- Real-time collaboration
- Live cursors
- Document sharing
- Version history
- Presence
- Redis Pub/Sub
- Docker
- Scalable architecture

## Tech Stack

Frontend:
- React
- Vite
- Tailwind CSS
- Socket.IO Client

Backend:
- Node.js
- Express
- MongoDB
- Socket.IO
- JWT

Infrastructure:
- Redis
- Docker
